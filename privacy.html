隱私權條款

最後更新：2026年10月

本隱私權條款說明 3mi-agent（以下簡稱「本應用程式」）如何收集、使用、處理和保護您的個人數據。我們致力於維護您的隱私和數據安全。

1. 我們收集的信息

當你使用本應用程式並通過 Google OAuth 登入時，我們在獲得你的同意後，可能會收集以下信息：

  • 基本 Google 帳戶信息：你的名稱、電子郵件地址和個人資料圖片
  • Google Workspace 數據（根據你授權的範圍）：
    • Gmail 郵件內容和元數據
    • Google Calendar 行事曆事件和細節
    • 其他已授權的 Google 服務數據
  • 使用數據：你與本應用程式的交互記錄，幫助我們改進服務

2. 我們如何使用你的信息

我們收集上述信息的目的是為了向你提供和改進本應用程式的服務：

  • 驗證你的身份並創建你的帳戶
  • 提供 AI 助手相關的核心功能（如郵件管理、行事曆同步等）
  • 根據你的授權執行特定任務和自動化流程
  • 改進我們的 AI 模型和用戶體驗
  • 提供客戶支持和技術協助
  • 除非法律要求，我們絕不會將你的數據出售、分享或披露給第三方

3. Google API 服務用戶數據政策

本應用程式從 Google API 接收的信息的使用和轉移應遵守 Google API 服務用戶數據政策，包括所有限制使用要求（Limited Use Restrictions）。

我們確保：

  • 只在提供本應用程式功能的必要範圍內使用 Google 數據
  • 不會將 Google 數據用於個性化廣告或其他商業目的
  • 不會將 Google 數據轉移給未經授權的第三方
  • 對所有收集的 Google 數據實施安全保護措施

4. 數據安全和保護

我們採用業界標準的安全措施保護你的數據：

  • 所有通訊都通過加密的 HTTPS 連接進行
  • 數據存儲在安全的服務器上，採用加密存儲
  • 訪問控制和身份驗證機制限制對敏感數據的訪問
  • 定期進行安全審計和漏洞掃描

5. 數據保留和刪除

我們遵循以下數據保留政策：

  • 主動數據：只要你的帳戶保持活躍，我們會保留必要的數據以維持服務
  • 帳戶刪除：刪除帳戶後，我們將在30天內刪除所有關聯的個人數據
  • 日誌數據：系統日誌通常在90天後自動刪除

6. 你的權利

你有權對自己的數據進行以下操作：

  • 存取權：要求查看我們持有的關於你的所有數據
  • 更正權：要求更正任何不準確的個人信息
  • 刪除權：要求刪除你的個人數據（「被遺忘權」）
  • 撤銷授權：隨時撤銷本應用程式對你 Google 帳戶的訪問權限
  • 數據可攜性：以常見格式獲取你的數據副本

7. 聯繫我們

如果你對本隱私權條款有任何疑問，或者想要：

  • 撤銷本應用程式的授權
  • 請求刪除你的個人數據
  • 提出隱私相關的投訴或顧慮

請通過以下方式聯繫我們：

  • 電子郵件：sammy.ms3@gmail.com
  • 支持中心：提交問題或反饋

8. 政策變更

我們可能會不時更新本隱私權條款以反映法律或服務的變化。任何重大變更都會通過電子郵件通知你，並在應用程式中公佈。持續使用本應用程式表示你接受修改後的條款。

9. 遵守法律

本應用程式遵守所有適用的隱私法律和法規，包括但不限於：

  • GDPR（歐盟通用數據保護條例）
  • CCPA（加州消費者隱私法）
  • 台灣個人資料保護法
  • 其他相關司法管轄區的隱私法
